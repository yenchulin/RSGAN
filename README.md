# RSGAN

Review Summarization Generative Adversarial Network.

## The Framework

![RSGAN framework](https://github.com/yenchulin/RSGAN/raw/master/rsgan_framework.png)

We first preprocess the product reviews and derive an aspect feature sequence and a sentiment feature sequence from them. Second, based on the aspect and sentiment feature sequences derived from the previous phase, we leverage RSGAN to generate the summary from the preprocessed product reviews.

RSGAN contains a generator and a discriminator, where the generator generates the summary word by word, sentence by sentence, and aspect by aspect. The goal of the generator is to generate a summary close to the reference ones to confuse the discriminator, while the responsibility of the discriminator is to learn the distribution of reference summaries so that it is able to discriminate between the reference summaries and the ones generated by the generator.

![generator architecture](https://github.com/yenchulin/RSGAN/raw/master/generator_architecture.png)

The generator architecture is shown above. It contains an encoder and a decoder. The encoder first encodes the input into a latent representation, while the decoder decodes the representation and generates a summary with the help of three attention mechanisms, namely state, aspect, and sentiment.

The encoder is implemented by a bidirectional LSTM model. It reads the input sequence forward and backward, then creates two hidden states which are concatenated together later on.

## Requirements

The repository is written with the TensorFlow framework. It requires the following main packages:

- Python 3
- tensorflow-gpu == 1.12 / 1.13
- tensorboardX
- rouge
- nltk

## Prepare the data

The original dataset is crawled by the [BestbuyReviewCrawler repository](https://github.com/yenchulin/BestbuyReviewCrawler).

For more information on preparing the data, please refer to the [RSGAN_Preprocessing repository](https://github.com/yenchulin/RSGAN_Preprocessing).

When the data is ready, please place the training data in `./review_generation_dataset/train/` and the test data in `./review_generation_dataset/test/`. As for the vocabulary file of training and testing data, please place them in `./review_generation_dataset/`. Also, retrieve the HAC result files `topicX_H_vocab.txt` and `topicX_H.npy` from the [RSGAN_Preprocessing repository](https://github.com/yenchulin/RSGAN_Preprocessing), and place them in `./review_generation_dataset/`.

## How it works

To verify if the model can run:

```bash
bash run.sh # or run.bat if Windows
```

To really train and test the model:

```bash
cp ./run_hparm.sh ../
cd ..
cp -avr ./RSGAN/ ./RSGAN_copy/
bash run_hparm.sh # or run_hparm.bat if Windows
```

The default options can be edited in `main.py`.

## Output Folder Description

`discriminator_train` stores training data for our discriminator. Under this folder, the `positive` folder stores the real-data text, and the `negative` folder stores the generated text.

`discriminator_test` stores testing data for our discriminator.

`discriminator_result` stores the reward scores calculated by our discriminator at different training steps.

`MLE` stores the text generated by a pre-trained generator on the testing set. Under this folder, `MLE_sample_negative` stores the data generated by a sampling mechanism. `MLE_max_temp_negative` stores the data generated by a maximum probability mechanism, which always chooses words with the highest probability. To show what high-quality reviews should be, we also provide the real-data text at folder `MLE_sample_positive` and `MLE_sample_positive`.

`train_sample_generated` stores the data generated by RSGAN using a sampling mechanism on training data.

`test_sample_generated` stores the data generated by RSGAN using a sampling mechanism on testing data.

`test_max_generated` stores the data generated by RSGAN using a maximum probability mechanism on testing data.

## Comparison Methods

We compared RSGAN with [Pointer-Generator (See et al. 2017)](https://arxiv.org/abs/1704.04368) and [MeanSum (Chu and Liu 2019)](https://arxiv.org/abs/1810.05739).

We modified the code of the two papers in order to fit our situation. The modified version can be accessed here: [Pointer-Generator](https://github.com/yenchulin/pointer-generator), [MeanSum](https://github.com/yenchulin/MeanSum)

## Automatic Evaluation

We evaluate the performance using three ROUGE scores, namely ROUGE-1, ROUGE-2, and ROUGE-L.

In addition, to reduce the sampling bias, we randomly sampled 5 pairs of training and testing datasets as described in [RSGAN_combination repository](https://github.com/yenchulin/RSGAN_combination). For each pair of training and testing datasets, we performed the experiment to compute the ROUGE scores of each compared method. Then we derived the averages and the 95% confidence intervals of the ROUGE scores for each compared method.

The results can be found [here](https://drive.google.com/drive/folders/1xtv8gPjayhdnQ7t7tXObI8V4ZR0Erh3O?usp=sharing).

## Human Evaluation

We follow the work of [DUC 2005 (Dang 2005)](https://duc.nist.gov/pubs/2005papers/OVERVIEW05.pdf) to rank the generated summaries by 5 linguistic measures: grammaticality, non-redundancy, referential clarity, focus, and structure and coherence.

The human evaluation questionnaire and the results are located [here](https://drive.google.com/drive/folders/1xtv8gPjayhdnQ7t7tXObI8V4ZR0Erh3O?usp=sharing).
